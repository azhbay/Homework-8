CSS Box Model

1. Неправильная карточка: content-box

Неправильная карточка

Ширина 364 px

Пояснение:

При box-sizing: content-box свойство width задаёт только ширину содержимого.

К ней дополнительно прибавляются внутренние отступы и границы:

320 + 20 + 20 + 2 + 2 = 364 px.

Карточка выходит за пределы контейнера на 44 px.

2. Правильная карточка: border-box

Исправленная карточка

Ширина 320 px

Пояснение:

Для карточки задано box-sizing: border-box.

Теперь width включает содержимое, внутренние отступы и границы.

Общая ширина карточки составляет ровно 320 px.

320 - 40 - 4 = 276 px содержимого.

Карточка полностью помещается в контейнер.
